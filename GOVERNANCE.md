# Project governance / Gouvernance

CamStudio Pro is an independent open-source project initiated and maintained by **@trigameyt**.

Everyone can suggest features, report bugs, fork the source, and submit Pull Requests (subject to repository visibility and permissions). AI-assisted contributions are welcome when the contributor verifies their changes and clearly discloses substantial AI assistance.

The human maintainer controls the official **`main`** branch, the release process and which contributions are accepted. Contributors should propose work through Issues, use a feature branch, include tests and documentation, and request review.

## Proposed protection policy

- Merge changes into `main` through reviewed Pull Requests.
- Require green automated Windows and Android checks once configured.
- Forbid deletion and force pushes on `main`.
- Official releases are published only by the maintainer.

**Note:** These are project rules, not automatically enforced by GitHub. A repository administrator must activate branch rules in Settings (see [docs/COMMUNITY_SETUP.md](docs/COMMUNITY_SETUP.md)).

La communauté peut contribuer ; le responsable conserve la validation des versions officielles.
