# Contributing

Thanks for helping improve this open-source, local-first Android webcam project.

- Discuss large features in a GitHub issue before starting.
- Keep all functionality video-only, independent of cloud services and respectful of Android camera consent.
- Never commit pairing keys, signing keys, credentials, real user profiles or personal recordings.
- For Windows, run unit tests and relevant windows/test_v*.py smoke scripts. Python 3.12 is recommended.
- For Android, compile using Android Studio with SDK 35 and JDK 17/21 and test physical device permissions.
- Explain any change to security, permissions, frame rates, platform compatibility and file formats.
- Include exact reproduction steps and redacted screenshots for bug reports.
