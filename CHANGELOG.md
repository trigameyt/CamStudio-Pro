# Changelog

## V1.0.0 RC1 — préparation GitHub

- Détection USB automatique, reconnexion après clé et autorisation ADB.
- Une seule instance Windows ; une relance réaffiche la fenêtre masquée.
- Sauvegarde automatique des réglages, écriture atomique, clé protégée par Windows DPAPI.
- Bouton Afficher/Masquer clé et Copie avec effacement différé du presse-papiers.
- Clé Android conservée entre les redémarrages et bouton de régénération.
- Documentation FR / EN et sécurité. Aucune fonction audio.
