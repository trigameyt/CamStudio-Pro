# Community Code of Conduct

This community welcomes respectful feedback, contributors of all experience levels, and responsible use of AI tools.

## Expected

Be kind, clear, constructive, transparent about test results, and considerate of others. Give credit for contributions and report bugs with reproducible steps.

## Not allowed

Harassment, threats, discriminatory abuse, doxxing, intentional credential leaks, spam, malware or intentionally misleading contributions.

## Moderation and reporting

For ordinary conduct issues, contact project maintainer **@trigameyt** through an appropriate GitHub channel. Do not disclose private details in public Issues. For vulnerabilities, use GitHub private vulnerability reporting **if enabled**; otherwise request a private contact method without posting the exploit publicly.

The maintainer may remove comments, close issues, refuse contributions or restrict interactions, using proportional responses.

This is an independent project and is not affiliated with OpenAI.
